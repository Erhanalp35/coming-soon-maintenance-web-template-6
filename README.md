# Coming Soon Maintenance Web Template 6

A responsive and polished **coming soon and maintenance web template** built with HTML5, CSS3, and Vanilla JavaScript.

This template is designed for websites, products, applications, startups, SaaS platforms, and online services that need a professional temporary page before launch or during scheduled maintenance.

It provides a lightweight standalone frontend for launch announcements, downtime messaging, service availability updates, maintenance information, and user guidance.

## Features

- Coming soon page
- Maintenance page
- Responsive layout
- Launch-focused messaging
- Service availability information
- Maintenance status presentation
- CTA elements
- Light Mode
- Dark Mode

## Light & Dark Mode

The template supports both Light Mode and Dark Mode.

Users can switch between themes using the built-in theme toggle.

The selected preference can be stored using browser localStorage so the chosen theme remains active after refreshing the page.

Both themes are designed to preserve:

- Readable typography
- Clear CTA buttons
- Visible status information
- Consistent component styling
- Appropriate contrast
- Polished visual hierarchy
